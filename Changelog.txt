[MAJOR FEATURES & ENHANCEMENTS]

BraveLite v1.66 - Official Release Changelog
Author: GrGeorge
================================================================================

[MAJOR FEATURES & BUG FIXES]
1. Chrome Web Store Native "Add to Chrome" Button Integration & Frictionless Installation:
   - Full implementation of `chrome.webstorePrivate` API bridge (`beginInstallWithManifest3`, `install`, `getExtensionStatus`, `enable`, `completeInstall`) injected at `DocumentCreation` to hook native Google WebStore actions before page scripts run.
   - Added capturing DOM event listener on Chrome Web Store buttons ("Add to Chrome", "Add to Brave", etc.), accurately extracting extension IDs from detail URLs and dispatching CRX downloads directly from Google client services.
   - Overhauled download handling (`handleDownload`) to automatically intercept WebExtension CRX packages and Google update URLs, routing them directly into BraveLite's Extensions directory without popping modal file picker dialogs, and registering them via `QWebEngineExtensionManager`.
   - Maintained the floating "⚡ Add to BraveLite" badge on WebStore pages as a persistent fallback installation mechanism.

2. Ubiquitous Find in Page (Ctrl+F) Everywhere:
   - Fixed Qt ambiguous shortcut collision caused by duplicate keybind registration of `"Ctrl+F"`.
   - Implemented an application-level event filter (`qApp->installEventFilter(this)`) in `BrowserWindow`, ensuring `Ctrl+F` and `Meta+F` are captured reliably across all windows, child frames, and active widgets.
   - Installed event filtering on `CustomWebView` and its Chromium `focusProxy()`, preventing the internal Chromium widget from consuming key events.
   - Injected a capturing `keydown` listener across all web pages in `BraveLiteCosmeticAndYTShield` communicating `BRAVELITE_OPEN_FIND::` via the console message channel, preventing websites from hijacking or suppressing `Ctrl+F`.
   - Added "Find in page...\tCtrl+F" to both the 3-dots App Menu and the web page right-click context menu.
   - Centralized `openFindDialog()` logic to immediately focus, select input, and update match counts across normal and split views.

3. Full Windows & Linux Cross-Platform Compatibility:
   - Standardized all extension storage and profile directory resolutions via `QStandardPaths::ConfigLocation` (`%APPDATA%/BraveLite` on Windows and `~/.config/BraveLite` on Linux).
   - Validated IPC single-instance socket naming (`BraveLiteSingleInstanceServer_v166`) and Windows installer definition (`installer.iss`).

4. Version Bump:
   - Elevated application version, diagnostic crash reporter, IPC server name, and engine identifiers to v1.66.

[MAJOR FEATURES & ENHANCEMENTS]
1. Middle-Click New Tab for Links & YouTube Videos:
   - Middle-clicking any link or YouTube video/thumbnail/title now reliably opens
     in a new tab without losing your place or navigating away from the current page.
   - Removed the request blocker that incorrectly treated middle-click background tabs
     as popups.
   - Added native auxclick event interceptor for YouTube Single Page Application components
     (rich grids, video renderers, thumbnails, and title links).

2. Omnibox Autocomplete in Address Bar:
   - Added instant autocomplete dropdown in the URL/Address bar as you start typing.
   - Intelligently suggests matches from your saved Bookmarks, Browsing History, and
     top visited domains with rich dark-theme styling.
   - Pressing Enter or clicking any suggestion immediately navigates to that destination.

3. F5 Shortcut for Page Refresh:
   - Added standard F5 keyboard shortcut to refresh/reload the active page or search.

4. External Links & Task Manager Fullscreen Fix:
   - Fixed bug where opening links from external applications (Discord, Telegram, mail)
     or launching a new window from task manager / taskbar would open or get stuck in fullscreen.
   - Cleanly restores normal/maximized window state with address bar and tabs visible.

5. Smooth, Lag-Free Fullscreen Transitions (YouTube & Video):
   - Completely resolved choppy, laggy, and glitchy fullscreen entry and exit on YouTube.
   - Eliminated jittery double window manager resizes and duplicate Escape action triggers.

6. Background Windows Ollama Installer with Progress Bar:
   - Updated the 1-click Ollama installer for Windows to run:
     "irm https://ollama.com/install.ps1 | iex" in background mode.
   - Added a sleek animated progress bar while downloading and installing without
     popping up any physical console windows.

7. Fast Tab Dragging & Synchronization Fix:
   - Connected tabMoved events to synchronize underlying tab stack pages with the tab bar.
   - Fixed tab titles changing while the page content stayed stuck when dragging tabs fast
     left-to-right and right-to-left.

8. Complete Overhaul of Themes:
   - Overhauled all 5 built-in theme profiles (BraveLite Dark, Midnight OLED,
     Cyberpunk Neon, Nordic Frost, Catppuccin Mocha).
   - Added customized theme-matched slim rounded scrollbars (vertical & horizontal).
   - Added modern polished styling for tabs, menus, tooltips, dialogs, and splitter dividers.

9. Dynamic Tab Shrinking for Overflow Prevention:
   - Tabs now dynamically shrink (from 200px down to 36px) as more tabs are opened.
   - Prevents the window from expanding horizontally across multiple monitors when
     opening many tabs.

10. Bookmarks Overflow Dropdown & Manager Create/Delete:
    - Added an overflow chevron ("»") dropdown on the bookmarks bar when bookmarks reach
      the end of the window.
    - Added "➕ New Bookmark" and "🗑 Delete Selected" options directly inside Bookmarks Manager.

11. Minimalistic & Compact In-Page Find (Ctrl+F):
    - Added a sleek, compact floating find bar (Ctrl+F) with instant live search highlights,
      match counter ("1/5"), Previous (▲ / Shift+Enter), Next (▼ / Enter), and Close (Esc).

12. Multi-Slot Bookmark Drag-and-Drop:
    - Overhauled bookmark reordering to allow dragging a bookmark across any number of
      slots at once in a single smooth mouse drag, exactly like dragging tabs.

13. Spotify Audio & Web Player Playback Fix:
    - Fixed Spotify web player (open.spotify.com) failing to play songs by updating
      browser User-Agent to standard Chrome and configuring Widevine DRM / media codec flags.
