================================================================================
BraveLite v1.11 - Official Release Changelog
Author: GrGeorge
================================================================================

[SEARCH ENGINE & AI UPGRADES]
1. Renamed Local Search Engine to "BraveLite Engine":
   - Rebuilt the search engine UI and functionality as a carbon copy of DuckDuckGo's
     dark theme (#1c1c1c background, DuckDuckGo header bar with clear/submit controls,
     All/Images/Videos/News/Maps category tabs, favicon + domain breadcrumbs, and
     instant organic web results).

2. Carbon Copy of Google's "AI Overview":
   - Redesigned the AI Overview card on BraveLite Engine to match Google's AI Overview:
     4-color sparkle icon, animated shimmer skeleton loader while generating, structured
     summary + bulleted key points, expandable "Show more / Show less" button, and
     a right-hand rail of clickable source citation cards.
   - Grounded BraveLite AI Overview with live DuckDuckGo search snippets so answers are
     accurate and based on real web results.

3. Fixed BraveLite AI Hover Link Summarizer:
   - Fixed child-element mouseout events prematurely canceling the hover timer when
     hovering over links containing spans or icons.
   - Added automatic cancellation of stale network requests, a 2.2s fast-fallback
     timeout, and anchor/title context fallback so link summaries always appear.

4. GPU Detection & Hardware Acceleration for BraveLite AI:
   - Added automatic GPU detection (NVIDIA via nvidia-smi, AMD/Intel via lspci &
     /dev/dri/renderD128 on Linux, and WMIC VideoController on Windows).
   - Added a "Use GPU Acceleration" toggle in Settings -> BraveLite AI (Ollama) that
     passes `"options": {"num_gpu": -1}` to offload LLM layers onto the GPU, plus a
     "Re-Scan GPU Hardware" button.

[PERFORMANCE & IDLE CPU DEBLOATING]
5. Eliminated Idle CPU Usage (0% CPU at Idle):
   - Removed the 100ms setInterval polling loop and full-page MutationObserver that
     previously ran across web pages.
   - Hooked YouTube ad-skipping and SponsorBlock directly into native HTML5 `<video>`
     events (`play`, `loadedmetadata`, `durationchange`, `timeupdate`).
   - Replaced the linear O(N) adblock domain list scan with an O(1) QSet hash lookup.
   - Throttled the New Tab page clock and paused updates when the tab is hidden.

[PREVIOUSLY ADDED IN v1.11]
6. Single-instance IPC (Discord/external links open in existing window).
7. Fixed YouTube fullscreen exit unmaximizing the browser window.
8. Added pagead.js, freshmarketer.com, claritybt.freshmarketer.com, and
   fwtracks.freshmarketer.com to AdBlocker.
9. Added 5 Theme Profiles and customizable Keybinds tab in Settings.
10. Drag-and-drop reorderable bookmarks on the bookmarks bar.
11. Live real-time download card insertion in already-open Downloads tabs.
12. Extensive crash & diagnostic logs with stack traces and system telemetry.
